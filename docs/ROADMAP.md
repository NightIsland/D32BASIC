# Roadmap

1. **Foundations** *(this step)*: repo, toolchain, `.NEX` build, the oracle
   and test harness, and specs for tokens, floating point and the memory map.
2. **Core language**: line editor, tokeniser and `LIST`; expressions,
   variables, strings and arrays (with garbage collection); control flow;
   `PRINT`/`INPUT`; maths and string functions; the 32x16 text screen and
   keyboard.
3. **Finish the MVP**: SD file commands (`SAVE`, `LOAD`, `MERGE`, `DIR`,
   `KILL`); PMODE graphics (`PCLS`, `PSET`, `LINE`, `CIRCLE`, `PAINT`, `DRAW`,
   `GET`/`PUT`); `PLAY` and `SOUND` on the AY chip; checks on a real Next; a
   release `.NEX`.
4. **Next extensions**: new PMODEs for Next hardware, planned once the MVP is done.
